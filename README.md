# FlightReady ✈️

FlightReady is a flight connection risk assessment tool
that uses real-world flight data.

## Problem
Flight delays can cause passengers to miss connecting
flights. Passengers may struggle to understand how a delay
affects their onward journey.

## Solution
FlightReady retrieves flight information and estimates
whether a connecting flight is safe, at risk, or likely
to be missed.

## Planned Features
- Search using two flight numbers
- Retrieve flight information using an API
- Calculate available connection time
- Display a connection risk assessment
